# c_sharp_app

Repositório da aplicação C# **RHFP Legado**, um sistema web ASP.NET MVC 5 (.NET Framework 4.8) para gestão de recursos humanos.

A solução está em [`LEGADO/rhf/RHFP.sln`](LEGADO/rhf/RHFP.sln). A aplicação web é o projeto `RHFPMVC`; os demais projetos cobrem regras de negócio, repositórios, modelo de dados e DTOs.
